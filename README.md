Two-Wheel Self-Balancing Robot

A two-wheel inverted-pendulum balancing robot built on the Arduino UNO R4 WiFi, with custom firmware implementing sensor fusion and cascaded PID control.

Hardware
- Microcontroller: Arduino UNO R4 WiFi 
- IMU: MPU-6050
- Motor Driver: TB6612FNG dual H-bridge
- Motors: 2× N20 12V 300RPM gearmotors with quadrature encoders
- Power: ~11.1V supply
